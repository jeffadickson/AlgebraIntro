# Start learning algebra

Open `Algebra_Adventure.html` in a desktop browser. Everything needed by the course is inside that file. Choose Quinn or Reagan at the top so each child has a separate saved place. Use the same file and browser next time.

## The first session

Bring about 20 counters (buttons or blocks work), paper, and a pencil. Start at episode 1, **Equals means same value**.

1. Make two groups of five counters. Ask: “What does the equals sign tell us?” It means the two sides have the same value.
2. Try `5 = 3 + 2`. Ask whether it is true and why. The answer is yes: equality works in either direction.
3. Predict one worked-example step, reveal it, and explain it together.
4. Try the live activity and a few practice questions. Let the child draw, speak, or use counters. Help is part of learning.
5. Ask the child to show how they checked one answer. Stop after about 10–15 minutes, or sooner if needed. An episode can take several sessions.

## Next time

Return to the child's profile. Ask what they remember. “Try a later check” generates another question for the current episode; hints and solution steps are still available. The fixed episode checkpoint has its answer in the grown-up guide.

Move on when the child can explain a new example and check it. If that takes help, keep using the model and revisit another day. Correct-answer counts are not a mastery score. Children can work at different paces; no lesson is locked.

Episodes 1–11 are the core course. Episode 12 is optional. Pause within episode 6 before dividing equal groups, and within episode 10 before replacing a letter with a whole expression. Revisit earlier ideas even after reaching mixed practice.

## Which offline option?

The HTML course itself makes no network requests. An ordinary browser can still access the internet outside this file. For the dedicated Windows reader, follow `viewer/README.md` and the packaged `READ-ME-FIRST.md`: extract the complete application folder and install its firewall rules. No .NET installation is needed to run the packaged reader.

Progress is stored on this device, in this browser or reader. It does not sync between devices. Clearing storage can erase it. Reset in the grown-up guide affects only the selected explorer and asks for a second confirmation.
